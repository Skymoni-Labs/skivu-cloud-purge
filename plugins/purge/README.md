# 小云 · 提示词注入

维护者：Skivu。正常界面不展示上游署名；原始版权、许可和来源资料保留在许可文件中。

本版本仅保留原包提示词注入及撤销。打开并启用后，可在宿主的角色下拉框选择任意角色并单独注入、读回核验、撤销。普通角色首次选择不会自动写入；小云保留旧版开关行为。正文不在插件页面或日志中展示。各角色开关独立持久化。

原提示词来源仅为用户提供的 dsh-purge 1.1.71 包中 `asset-table.js` 的加密槽，通过原 `table-read.js` 与 `table-key.js` 进行数据解码。构建检查源文件 SHA，输出摘要和字节数，不输出正文；不导入或执行原 DSH 宿主与补丁代码。来源与许可证见 `upstream/` 以及 `PROVENANCE.json`。

要求宿主 >=0.2.96，权限只有 `prompt` 和开关状态所需的 `storage`。注入成功须写入确认、读回全文一致且前后均为同一个所选角色上下文；遇到错误、上下文改变、结果不一致会显示未能确认，不会虚报成功。状态指向提示词配置，不保证模型行为。
