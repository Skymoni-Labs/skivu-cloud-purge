# 小云 · 提示词注入

仅保留用户提供的 dsh-purge 1.1.71 原包提示词注入。原作 [YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge)，Copyright (c) 2026 小杨；原 LICENSE、README 署名与附加使用说明保留在 `plugins/purge/upstream/`。免费分发。

需要 Skivu 0.2.96 或更新版本。安装并启用后打开插件，在小云上下文中自动注入；页面只显示核验状态及注入、撤销按钮，提示词正文不进入页面或日志。撤销状态会保存，重新打开不会自行开启。停用整个插件后，其提示词贡献由宿主停止使用。

“注入成功”要求宿主确认保存后，读回的小云角色及完整正文与原包逐字一致；只收到写入回执、读回不符、权限失败或上下文改变均不会显示成功。此状态说明后续请求的提示词配置已保存并核验，不代表某个模型一定遵循内容。

1.1.0 移除了规则编辑器、技能库、演练、资料录入、数据库、评分、报告、备份和所有模型工具贡献。只声明 `prompt` 与用于记住注入开关的 `storage` 权限，不调用内置 Linux、资料库或文件接口，不包含独立 DSH 运行器。旧版资料不会由升级过程主动删除。

```sh
cd plugins/purge
npm run build
npm test
```

只使用 Node 内置库，无第三方构建依赖。构建仅解码原包的独立加密提示词槽作为数据，不加载 DSH 安装、补丁或宿主代码；正文不打印。安装包位于 `plugins/purge/dist/`，发行包位于 `packages/`。历史功能保留在旧版 Git 标签中。
